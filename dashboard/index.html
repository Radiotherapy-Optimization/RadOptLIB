Download script

For any number of files, with nothing to install. Save the script into the folder where the files should go and run it. It can be run again: complete files are skipped and interrupted downloads are resumed.

Windows: double-click the saved file. macOS and Linux: run sh radoptlib-download.sh in a terminal. The scripts use curl, which is part of Windows 10 and later, macOS and Linux.
